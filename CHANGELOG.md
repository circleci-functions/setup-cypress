# Changelog

All notable changes to setup-cypress will be documented in this file. Each release's section is
added by its release PR (see [RELEASE.md](RELEASE.md)) and becomes its GitHub release notes.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-20

The first release: `install` and `run`.

### What's Changed
* Add a minimal CircleCI config and CODEOWNERS by @mangyau in https://github.com/circleci-functions/setup-cypress/pull/1
* Scaffold setup-cypress from setup-browserbase by @mangyau in https://github.com/circleci-functions/setup-cypress/pull/2
* Install and cache the Cypress binary by @mangyau in https://github.com/circleci-functions/setup-cypress/pull/3
* Run a Cypress suite with circleci testsuite by @mangyau in https://github.com/circleci-functions/setup-cypress/pull/4
* Store screenshots, videos and JUnit reports as artifacts by @mangyau in https://github.com/circleci-functions/setup-cypress/pull/5

**Full Changelog**: https://github.com/circleci-functions/setup-cypress/commits/v0.1.0
